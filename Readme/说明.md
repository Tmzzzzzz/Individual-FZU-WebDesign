# 福州大学主页项目说明

本文档用于说明本项目从初始页面到当前版本的主要改动、实现过程、留言板 JavaScript 逻辑，以及 CSS 文件在页面设计中的具体作用。

## 一、页面改动清单与实现过程

### 1. 项目基础结构搭建

项目采用 HTML、CSS、JavaScript 三件套实现，主要文件如下：

- `index.html`：负责网页内容结构。
- `style.css`：负责页面布局、色彩、字体、卡片、按钮、响应式效果。
- `script.js`：负责留言板的数据保存、展示、删除和清空。
- `assets/`：存放福州大学相关图片素材。

实现过程：

1. 在 `index.html` 中创建基本 HTML 页面结构。
2. 通过 `<link rel="stylesheet" href="style.css">` 引入 CSS 文件。
3. 通过 `<script src="script.js"></script>` 引入 JavaScript 文件。
4. 页面内容按照“顶部导航栏、首页、基本信息、校园展示、留言板、底部版权区”的顺序组织。

### 2. 顶部导航栏优化

最初导航栏包含“首页、基本信息、教务处、留言板”。后续根据页面逻辑进行了调整：

- 将“教务处”从导航栏移出，放入首页按钮区。

- 最终增加了浅红渐变背景、深红点阵纹样、斜向纹样和顶部深红渐变线。

实现过程：

1. 在 `index.html` 的 `<header>` 中使用 `.site-header` 包裹 logo 和导航链接。
2. 使用 `.nav-links` 管理导航按钮排列。
3. 在 `style.css` 中使用 `position: fixed` 固定导航栏。

## 二、留言板功能实现过程与 JavaScript 逻辑

留言板功能由 HTML 表单、页面列表和 `script.js` 共同完成。

### 1. HTML 结构

留言板主要包含两部分：

- 用户留言区
- 管理员查看区

用户留言区代码结构：

```html
<form id="messageForm">
  <input id="nickname" name="nickname" type="text" required>
  <textarea id="message" name="message" required></textarea>
  <button type="submit">提交留言</button>
</form>
```

管理员查看区代码结构：

```html
<span id="messageCount" class="message-count">0 条</span>
<button id="clearMessages" class="danger-button" type="button">清空</button>
<ul id="messageList" class="message-list"></ul>
```

### 2. 获取页面元素

`script.js` 开头使用 `document.querySelector()` 获取页面元素：

```js
const form = document.querySelector("#messageForm");
const nicknameInput = document.querySelector("#nickname");
const messageInput = document.querySelector("#message");
const messageList = document.querySelector("#messageList");
const clearButton = document.querySelector("#clearMessages");
const messageCount = document.querySelector("#messageCount");
```

这些变量分别对应：

- `form`：留言表单。
- `nicknameInput`：昵称输入框。
- `messageInput`：留言内容输入框。
- `messageList`：留言展示列表。
- `clearButton`：清空留言按钮。
- `messageCount`：留言数量显示区域。

### 3. 使用 localStorage 保存留言

留言数据保存在浏览器本地的 `localStorage` 中。

```js
const storageKey = "fzuMessages";
```

`storageKey` 是保存留言数据时使用的键名。

获取留言：

```js
function getMessages() {
  const savedMessages = localStorage.getItem(storageKey);
  return savedMessages ? JSON.parse(savedMessages) : [];
}
```

逻辑说明：

1. 使用 `localStorage.getItem(storageKey)` 读取本地数据。
2. 如果有数据，就用 `JSON.parse()` 转换为数组。
3. 如果没有数据，就返回空数组 `[]`。

保存留言：

```js
function saveMessages(messages) {
  localStorage.setItem(storageKey, JSON.stringify(messages));
}
```

逻辑说明：

1. `localStorage` 只能保存字符串。
2. 留言数组需要先用 `JSON.stringify()` 转为字符串。
3. 再使用 `localStorage.setItem()` 保存。

### 4. 渲染留言列表

核心函数是 `renderMessages()`。

```js
function renderMessages() {
  const messages = getMessages();
  messageList.innerHTML = "";
  messageCount.textContent = `${messages.length} 条`;
}
```

它的作用：

1. 从本地读取所有留言。
2. 清空旧的留言列表。
3. 更新留言数量。
4. 如果没有留言，显示空状态提示。
5. 如果有留言，则逐条创建 HTML 元素并显示。

空状态：

```js
if (messages.length === 0) {
  messageList.innerHTML = '<li class="empty-tip">暂无留言，快来留下第一条吧！</li>';
  return;
}
```

留言展示：

```js
messages.forEach(function (item, index) {
  const li = document.createElement("li");
  const meta = document.createElement("div");
  const messageBody = document.createElement("div");
  const name = document.createElement("span");
  const time = document.createElement("span");
  const content = document.createElement("p");
  const deleteButton = document.createElement("button");
});
```

这里使用 `document.createElement()` 创建元素，而不是直接拼接大量 HTML 字符串。

这样做的好处：

- 结构更清楚。
- 可以更方便地绑定类名和数据。
- 使用 `textContent` 显示用户输入，可以避免把用户输入当成 HTML 代码执行，更安全。

### 5. 提交留言逻辑

提交留言使用表单的 `submit` 事件：

```js
form.addEventListener("submit", function (event) {
  event.preventDefault();
});
```

`event.preventDefault()` 的作用是阻止表单默认刷新页面。

完整流程：

1. 用户输入昵称和留言。
2. 点击“提交留言”。
3. JS 获取输入框内容。
4. 使用 `.trim()` 去掉首尾空格。
5. 如果昵称或留言为空，弹出提示。
6. 如果内容有效，创建一条留言对象。
7. 将新留言加入数组。
8. 保存到 `localStorage`。
9. 重新渲染列表。
10. 清空表单。
11. 弹出“留言成功，点此返回”。

留言对象结构：

```js
const newMessage = {
  nickname: nickname,
  content: content,
  time: new Date().toLocaleString()
};
```

每条留言保存三个信息：

- `nickname`：昵称。
- `content`：留言内容。
- `time`：提交时间。

### 6. 清空全部留言

清空按钮绑定点击事件：

```js
clearButton.addEventListener("click", function () {
  const confirmed = confirm("确定要清空所有留言吗？");

  if (confirmed) {
    localStorage.removeItem(storageKey);
    renderMessages();
  }
});
```

逻辑说明：

1. 点击“清空”按钮。
2. 弹出确认框。
3. 如果用户确认，就用 `localStorage.removeItem(storageKey)` 删除本地留言。
4. 调用 `renderMessages()` 更新页面。

### 7. 删除单条留言

每条留言都有一个“删除”按钮。

按钮创建时保存了当前留言的数组下标：

```js
deleteButton.dataset.index = index;
```

删除逻辑：

```js
messageList.addEventListener("click", function (event) {
  if (!event.target.classList.contains("delete-message")) {
    return;
  }

  const index = Number(event.target.dataset.index);
  const messages = getMessages();

  messages.splice(index, 1);
  saveMessages(messages);
  renderMessages();
});
```

逻辑说明：

1. 在整个留言列表 `messageList` 上监听点击事件。
2. 判断用户点击的是否是 `.delete-message` 按钮。
3. 读取按钮上的 `data-index`。
4. 使用 `splice(index, 1)` 删除对应留言。
5. 保存新的留言数组。
6. 重新渲染页面。

这种写法叫事件委托。好处是留言按钮是后续动态生成的，也能正常响应点击。

### 8. 页面加载时自动显示留言

文件最后调用：

```js
renderMessages();
```

作用是页面一打开，就从 `localStorage` 中读取已有留言并显示。

## 三、CSS 文件的具体作用与复杂色彩实现

`style.css` 是整个网页视觉效果的核心文件，负责：

- 页面基础样式重置。
- 全局字体和背景。
- 导航栏布局与纹样。
- 首页双栏布局。
- 图片卡片与信息卡片样式。
- 留言板表单与留言列表样式。
- 页脚样式。
- 响应式布局。

### 1. CSS 变量管理色彩

文件开头使用 `:root` 定义全局色彩变量：

```css
:root {
  --ink: #1d1f23;
  --muted: #515761;
  --home-soft: #ffd9df;
  --home-strong: #ef4d62;
  --about-soft: #cfe6ff;
  --about-strong: #2f80ed;
  --office-soft: #d6f3ca;
  --office-strong: #36a853;
  --message-soft: #ffe89a;
  --message-strong: #f3a712;
  --paper: #ffffff;
}
```

这样做的好处：

- 色彩统一，方便维护。
- 后续修改主题颜色时，只需要改变量。
- 各模块可以有明确的色彩分工。

当前色彩逻辑：

- 首页：红色系。
- 基本信息：蓝色系。
- 校园展示：蓝色系，与基本信息保持统一。
- 留言板：黄色系。
- 外链按钮：深红色。

### 2. 网页背景纹样

页面背景使用多层 `linear-gradient()` 制作几何纹样：

```css
body {
  background:
    linear-gradient(135deg, rgba(29, 31, 35, 0.045) 25%, transparent 25%),
    linear-gradient(225deg, rgba(29, 31, 35, 0.045) 25%, transparent 25%),
    linear-gradient(45deg, rgba(29, 31, 35, 0.03) 25%, transparent 25%),
    linear-gradient(315deg, rgba(29, 31, 35, 0.03) 25%, #f4f5f7 25%);
}
```

实现原理：

1. 多个渐变图层叠加。
2. 每层设置不同方向，如 `135deg`、`225deg`、`45deg`、`315deg`。
3. 使用透明色和浅灰色组合，形成简约几何纹样。
4. 使用 `background-size: 32px 32px` 控制纹样密度。

这种设计比大面积彩色光斑更简约高级。

### 3. 顶部导航栏复杂纹样

导航栏使用 `.site-header` 和 `.site-header::before` 共同实现。

主体背景：

```css
.site-header {
  background:
    linear-gradient(135deg, #fff7f8 0%, #ffdce2 48%, #ffc7d0 100%);
}
```

这是一层浅红渐变背景。

纹样层：

```css
.site-header::before {
  background:
    radial-gradient(circle, rgba(143, 29, 44, 0.16) 2px, transparent 2px),
    repeating-linear-gradient(135deg, rgba(143, 29, 44, 0.12) 0 5px, transparent 5px 18px),
    linear-gradient(90deg, #8f1d2c, #ef4d62, #8f1d2c);
}
```

三层效果分别是：

1. `radial-gradient()`：制作深红点阵。
2. `repeating-linear-gradient()`：制作斜向条纹。
3. `linear-gradient()`：制作顶部深红渐变线。

通过 `background-size` 控制纹样大小：

```css
background-size: 22px 22px, auto, 100% 6px;
```

含义：

- 点阵每 `22px` 重复一次。
- 斜纹按默认尺寸重复。
- 顶部色条宽度为 `100%`，高度为 `6px`。

### 4. 卡片样式

网页中大量使用卡片结构，例如：

- 首页介绍卡片 `.hero-text`
- 图片展示卡片 `.gallery-card`
- 基本信息卡片 `.info-card`

常用样式包括：

```css
border-radius: 24px;
box-shadow: 0 18px 48px rgba(24, 26, 32, 0.1);
border: 1px solid rgba(29, 31, 35, 0.12);
```

作用：

- `border-radius`：让卡片圆润。
- `box-shadow`：制造悬浮感。
- `border`：让卡片边界更清楚。

### 5. 按钮样式

按钮统一使用圆角胶囊形：

```css
border-radius: 999px;
```

首页按钮包括：

- `.primary-button`：红色。
- `.office-button`：深红色。

按钮悬停效果：


作用：

### 6. 留言板样式

留言板主要样式包括：

- `.message-layout`：控制留言区和管理员区双列布局。
- `.message-panel`：留言板卡片背景和边框。
- `input, textarea`：输入框样式。
- `.message-list`：留言列表。
- `.message-item`：单条留言卡片。
- `.message-count`：留言数量徽章。
- `.delete-message`：单条删除按钮。

输入框聚焦效果：

```css
input:focus,
textarea:focus {
  outline: 4px solid rgba(243, 167, 18, 0.22);
  border-color: var(--message-strong);
}
```

作用：

- 用户点击输入框时出现黄色外轮廓。
- 提醒用户当前正在输入。

### 7. 响应式布局

页面使用媒体查询适配不同屏幕。

当宽度小于 `1000px`：

```css
.info-grid {
  grid-template-columns: repeat(2, 1fr);
}
```

四张信息卡片从一行四列变为两列。

当宽度小于 `820px`：

```css
.hero,
.message-layout {
  grid-template-columns: 1fr;
}
```

首页和留言板从双列变成单列，更适合手机屏幕。

当宽度小于 `620px`：

```css
.info-grid {
  grid-template-columns: 1fr;
}
```

信息卡片改为单列排列。

响应式设计的目的：

- 保证网页在电脑、平板、手机上都能正常浏览。
- 避免文字和按钮挤在一起。
- 保持图片比例和卡片阅读体验。

## 四、总结

本项目最终实现了一个以福州大学为主题的静态网页，主要功能包括：

- 顶部导航栏。
- 首页介绍与外链按钮。
- 福州大学基本信息展示。
- 校园图片与主校区位置展示。
- 留言板提交、保存、展示、删除、清空。
- 页脚版权、联系方式和外部链接。

整个项目适合作为 HTML、CSS、JavaScript 入门练习。HTML 负责结构，CSS 负责视觉表现，JavaScript 负责交互逻辑，三者共同完成一个较完整的校园主页作品。
